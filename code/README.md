# Code

This folder is reserved for source-code organization as required by the training repository structure.

The working Notice Action Extractor application is maintained in the repository root to preserve its current Streamlit configuration and execution workflow.

## Main Application

- `app.py` — Streamlit dashboard
- `src/` — extraction, Gemini client, schema, fallback, and export modules
- `prompts/` — extraction and repair prompts
- `tests/` — project tests
